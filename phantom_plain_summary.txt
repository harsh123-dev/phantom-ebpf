PHANTOM monitors how software components behave after deployment. It connects a software bill of materials to kernel events collected with eBPF, then uses a graph and causal model to investigate whether a component change explains unusual activity. A separate scoring model helps analysts prioritize workloads but does not claim causation. The system can report when available evidence is insufficient for attribution. Supplied evaluation figures suggest useful detection performance and overhead, though they conflict with the results currently checked into the repository. That discrepancy must be resolved before publication. PHANTOM aims to make runtime supply-chain investigations more traceable, cautious, and useful.
